# รายงานทุกส่วนต่าง

เมื่อตัวเลขจากสองแหล่งไม่ตรงกัน ให้รายงานส่วนต่างพร้อมตัวเลขทั้งสองฝั่ง แล้วหยุดรอ ห้ามตัดสินเองว่าต่างน้อยพอจะข้ามได้

**Why:** ส่วนต่างเล็กน้อยสองครั้งที่ AI ปล่อยผ่าน ครั้งหนึ่งเป็นการปัดเศษจริง อีกครั้งเป็นของที่ส่งไม่ครบ ขนาดของส่วนต่างบอกไม่ได้ว่าเป็นแบบไหน คนที่รู้จักผู้ขายเป็นคนตัดสิน

**Pattern:**
1. เขียนตัวเลขทั้งสองฝั่งและส่วนต่างลงในผลตรวจ พร้อมชี้เอกสารและบรรทัด
2. ไม่ใช้คำว่า ใกล้เคียง ประมาณ หรือ น่าจะเป็นการปัดเศษ แทนตัวเลข
3. หยุดงานของใบนั้น และถามคนว่ารับส่วนต่างนี้ได้หรือไม่
4. เมื่อคนบอกเกณฑ์ที่รับได้ ให้จดเกณฑ์ลงใน playbook ของงานนั้น ไม่จำไว้เอง

**You skipped this if:** ผลตรวจบอกว่าตรง ทั้งที่ตัวเลขสองฝั่งในตารางไม่เท่ากัน
